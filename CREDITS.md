# CREDITS.md

## Art assets

The artwork in `assets/art/` was generated with OpenAI's native image-generation tool in Codex, under the Rat Trainer project's art direction. Character identity, environment continuity, palette and revisions were directed by the project owner. Generation prompts and review records are preserved in `design/assets/reviews/`; file provenance and migration hashes are recorded in `design/assets/art-migration.json`.

Princess Maker screenshots were consulted for broad historical visual references only. They are not included in the game's artwork. No third-party art or images from MagicTools were downloaded or copied into `assets/art/`.

The procedural fallback PNGs are generated by `src/core/procedural_placeholders.gd` and remain available when final art is missing.

| Asset | Source | Author | License | Usage | Placeholder or final |
|-------|--------|--------|---------|-------|-----------------------|
| Characters, portraits, backgrounds, event CGs, activity scenes, UI, icons, items, monsters and ending emblems | OpenAI native image generation in Codex; project references and prompts | Rat Trainer project, AI-assisted | No third-party image license attached | Project game art; see migration inventory for exact files | Final-art directory |
| `assets/art/reference/char_rat_sheet_base.png` | Same generation workflow | Rat Trainer project, AI-assisted | No third-party image license attached | Internal character reference | Reference only |
