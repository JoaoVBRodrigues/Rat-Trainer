# Start Skill

Initializes a new game project session.

## Usage

```
/start [project_name] [engine] [rigor_level]
```

## Parameters

- `project_name`: Name of the project (default: from project.yaml)
- `engine`: Target engine (godot, unity, unreal, web)
- `rigor_level`: Development approach - "minimal", "standard", "thorough"

## Example

```
/start Rat Trainer godot minimal
```

## Prompts

1. What is the project name?
2. Which engine are you using?
3. What is your development rigor level?
